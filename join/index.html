Java 版

Java 版加入方式

适用于 PC 端 Java 版玩家，通过 Via 多版本互通插件，可允许不同版本共同游玩。

服务器地址
bdwl.xiao-blog.top
登录方式
正版登录 + LittleSkin登录
游戏版本
1.10-26.2（建议版本：26.2）
  1. 启动 Minecraft Java 版，进入「多人游戏」
  2. 点击「添加服务器」，输入上方服务器地址
  3. 保存并加入，即可开始游戏
基岩版

基岩版加入方式

适用于手机、电脑端基岩版玩家，通过 Geyser 互通组件与 Java 版同服游玩。

服务器地址
bdwl.xiao-blog.top
端口
26756
游戏版本
26.0-26.45（建议版本：26.30+）
  1. 启动 Minecraft 基岩版，进入「服务器」标签页
  2. 添加外部服务器，填入地址与端口
  3. 保存并加入，即可开始游戏
